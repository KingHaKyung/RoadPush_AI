# RoadPush AI

Production package for photo semantic processing, Sidewalk/Road surface
post-processing, Phase 7-A boundary selection, and Phase 7-B connected
passability measurement.

Start with:

- `docs/PHASE7B_PRODUCTION_LOGIC.md` — final architecture and backend contract
- `docs/DEVELOPMENT_HISTORY.md` — full accepted/rejected development history
- `docs/DEPLOYMENT.md` — CPU/GPU setup and runtime roots
- `manifests/production_source_manifest.json` — frozen source inventory

The repository contains only production code and compact evidence. Full images,
models, phase-specific review tools, and the 160-case review archive are shipped
in the separate Drive experiment bundle.
